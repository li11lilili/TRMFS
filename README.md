# TRMFS

## Tensorized robust multimodal feature selection with dual-regularization for Alzheimer's disease diagnosis


### Code

Before running the code, please make sure the following software is installed:

- MATLAB R2022b
- LIBSVM, which is required for classification and can be downloaded from the [official website](https://www.csie.ntu.edu.tw/~cjlin/libsvm/)
